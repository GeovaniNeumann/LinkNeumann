# Neumann Web Solutions - Linktree

Página de links estilo Linktree feita com **React + Vite + CSS Modules + JavaScript**.

## Rodar

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

A pasta `dist/` pode ser publicada em qualquer hospedagem estática (Vercel, Netlify, Cloudflare Pages, etc).

## Editar links

Tudo fica em `src/data/links.js`: número do WhatsApp, mensagem padrão, Instagram, site, bio e a lista de botões.

## Imagens

- `src/assets/logo.webp`: foto de perfil
- `src/assets/wallpaper.webp`: fundo
- `public/favicon.webp`: favicon
